# হানাফি নিষিদ্ধ সময় — প্রদর্শন নীতি

অ্যাপে সূর্যোদয়, জাওয়াল/মধ্যাহ্ন এবং সূর্যাস্তের জ্যোতির্বৈজ্ঞানিক রেফারেন্স সময় AlAdhan Prayer Times API থেকে আসা Sunrise, Sunset এবং সেগুলোর মধ্যবিন্দু (solar noon) ব্যবহার করে দেখানো হয়। এই তিনটি রেফারেন্সকে সম্পূর্ণ ফিকহি নিষিদ্ধ সময়সীমা বলে দাবি করা হয় না।

হানাফি ফিকহে সূর্যোদয়ের পর সূর্য যথেষ্ট ওপরে ওঠা পর্যন্ত এবং সূর্যাস্তের আগে সূর্যের আলো ম্লান হওয়ার সময় পর্যন্ত নিষেধাজ্ঞার পরিসর থাকে। এ সময়ের দৈর্ঘ্য ভৌগোলিক অবস্থান, ঋতু ও পর্যবেক্ষণভেদে পরিবর্তিত হয়; আলাদা কোনো মানক API এই ফিকহি সীমা নির্ভুলভাবে সরবরাহ করে না। তাই অ্যাপ আনুমানিক মিনিটকে নিশ্চিত বিধান হিসেবে দেখায় না।

তাই অ্যাপের সময়সূচি সতর্কতামূলক জ্যোতির্বৈজ্ঞানিক রেফারেন্স; নির্দিষ্ট আমলের ক্ষেত্রে নিজের এলাকার নির্ভরযোগ্য হানাফি আলেম বা মসজিদের নির্দেশনা অনুসরণ করতে হবে।
