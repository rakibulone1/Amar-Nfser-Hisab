Release 1.3.0 is a frontend experience update:
- Mobile-first layout and safe-area-aware bottom navigation/content clearance.
- Dashboard-first behavior on browser refresh; section/history navigation resets scroll position.
- One consistent Dashboard return control for section headings.
- Sync indicator shows only server-confirmed state words, never a timestamp.
- Background autosave does not emit a global success toast; errors remain visible.
- Centered, compact personal footer without a copyright mark.
- Stronger section color grading, readable mobile typography, separated cards, and subtle motion with reduced-motion support.

No SQL migration, database schema, RLS/RPC/API contract, authentication logic, or dependency package is changed.
No .env.local, personal credentials, node_modules, .next, or .git data is included.
