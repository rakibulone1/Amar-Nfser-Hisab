- No new paid service, Storage bucket, Cron or Edge Function.

Database setup:
- Existing Release 1.1 database: back up first, then run `supabase/migrations/002_relational_workspace.sql` exactly once.
- New empty Supabase database: run `supabase/MASTER_DATABASE_SETUP.sql` exactly once; it already includes the Release 1.2 relational schema, so do not also run 001 or 002.
- Use `supabase/WORKSPACE_DATA_AUDIT_RELATIONAL.sql` with your own sign-in email to inspect row counts after migration.
