Database setup:
- Existing Release 1.0 database: run supabase/migrations/001_atomic_workspace_snapshot.sql once.
- New empty Supabase database: run supabase/MASTER_DATABASE_SETUP.sql once; do not also run the incremental migration.
- Run supabase/WORKSPACE_DATA_AUDIT.sql (read-only) to inspect the snapshot array counts and legacy table counts for your sign-in email.
